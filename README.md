# IAM Lab From Zero To Hero

The public landing page and setup manual for **IAM Lab From Zero To Hero**, a hands-on Identity & Access Management lab: a real Active Directory domain synced to your own Entra ID tenant and Okta org, five portfolio projects, and a local AI instructor.

- **Landing page:** https://pitchiluxe.github.io/iam-lab-from-zero-to-hero/
- **Setup & user manual:** [MANUAL.md](MANUAL.md)

The lab's code repository is private for now. To get access, use the contact form on the landing page and include your GitHub username.

Everyone in the lab directory is fictional. Screenshots show lab data only.
